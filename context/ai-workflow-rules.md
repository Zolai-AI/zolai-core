# AI Workflow Rules

## Guardrails
- Scope work to this repo; read this `context/` set + `AGENTS.md` + README (not the whole tree).
- Never commit secrets; never git-ignore-override to force secrets.
- Work on `main`, commit with Conventional Commits, keep tree clean (0 dirty) before push.
- Push to `origin` (`Zolai-AI/...`) only; do not force-push.
- Run the repo test/verify step before reporting done.
