### 6. Risks Identified

| Risk | Severity | Evidence |
|------|----------|----------|
| No foreign keys enabled | HIGH | All joins are implicit; referential integrity is unenforced |
| `*_import` staging tables not cleaned up | MEDIUM | 24 tables, ~1.8M rows of redundant staging data |
| 11 empty tables wasting schema space | LOW | Placeholder tables for abandoned features |
| Dictionary import has 44K entries not in canonical | MEDIUM | Possibly filtered during build, but not documented |
| Word alignments import has 627K rows vs 385K canonical | MEDIUM | 241K rows were filtered — filter criteria undocumented |

### 7. Recommendations

1. **Enable foreign keys** in WAL mode (single PRAGMA at connection)
2. **Drop 11 empty tables** or archive them
3. **Document the canonical build logic** — how `*_import` → canonical works
4. **Consolidate vocabulary** — deprecate `vocab` in favor of `zolai_vocabulary`
5. **Consolidate grammar** — deprecate `grammar_patterns` in favor of `zolai_grammar_patterns`
6. **Target schema:** ~35 tables (down from 71) by merging canonical + enhanced + dropping staging
7. **Phase 2:** Implement canonical build script that produces the target schema from current data
