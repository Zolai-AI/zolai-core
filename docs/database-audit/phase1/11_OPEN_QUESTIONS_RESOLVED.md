## Q1: Vocabulary Overlap

**Question:** How much overlap exists between `vocab` and `zolai_vocabulary`?

**SQL Evidence:**
```sql
-- Total counts
SELECT COUNT(*) FROM vocab;           -- 94,458
SELECT COUNT(*) FROM zolai_vocabulary; -- 112,279

-- Overlap (by headword = zolai)
SELECT COUNT(*) FROM vocab v JOIN zolai_vocabulary z ON v.headword = z.zolai;
-- 103,846

-- Vocab only
SELECT COUNT(*) FROM vocab WHERE headword NOT IN (SELECT zolai FROM zolai_vocabulary);
-- 17,565

-- Zolai vocab only
SELECT COUNT(*) FROM zolai_vocabulary WHERE zolai NOT IN (SELECT headword FROM vocab);
-- 8,433
```

**Answer:** `zolai_vocabulary` is the master table with 17,821 more entries. The overlap is 103,846 (with duplicates). `vocab` is a subset with some unique entries.

## Q2: Grammar Patterns Overlap

**Question:** How do `grammar_patterns`, `grammar_patterns_enhanced`, and `zolai_grammar_patterns` relate?

**SQL Evidence:**
```sql
SELECT COUNT(*) FROM grammar_patterns;          -- 5,547
SELECT COUNT(*) FROM grammar_patterns_enhanced;  -- 5,597
SELECT COUNT(*) FROM zolai_grammar_patterns;     -- 13,519

-- Overlap by pattern_id
SELECT COUNT(*) FROM grammar_patterns g JOIN zolai_grammar_patterns z ON g.pattern_id = z.pattern_id;
-- 5,597

-- Grammar patterns only (by pattern_id)
SELECT COUNT(*) FROM grammar_patterns g WHERE g.pattern_id NOT IN (SELECT pattern_id FROM zolai_grammar_patterns z);
-- 0
```

**Answer:** `grammar_patterns` is a strict subset of `zolai_grammar_patterns` (all 5,547 entries exist in the larger table). `zolai_grammar_patterns` has 7,922 additional patterns.

## Q3: Proverbs Overlap

**Question:** How do `proverbs` and `zolai_proverbs_idioms` relate?

**SQL Evidence:**
```sql
SELECT COUNT(*) FROM proverbs;              -- 7,736
SELECT COUNT(*) FROM zolai_proverbs_idioms; -- 4,984

-- Overlap by zolai text
SELECT COUNT(*) FROM proverbs p JOIN zolai_proverbs_idioms z ON p.zolai = z.zolai;
-- 4,984

-- Proverbs only
SELECT COUNT(*) FROM proverbs p WHERE p.zolai NOT IN (SELECT z.zolai FROM zolai_proverbs_idioms z);
-- 2,752

-- Zolai proverbs only
SELECT COUNT(*) FROM zolai_proverbs_idioms z WHERE z.zolai NOT IN (SELECT p.zolai FROM proverbs p);
-- 0
```

**Answer:** `zolai_proverbs_idioms` is a strict subset of `proverbs` (4,984 of 7,736). It adds richer metadata (morpheme_breakdown, cultural_context, theme) for those entries.

## Q9: Translations Delta

**Question:** Why does `translations` (212,754) have more rows than `translations_import` (135,511)?

**SQL Evidence:**
```sql
SELECT direction, COUNT(*) FROM translations GROUP BY direction;
-- en_to_zo: 29,255
-- en→my: 154,060
-- zo_to_en: 29,439

SELECT source, COUNT(*) FROM translations_import GROUP BY source;
-- TDB_KJV: 60,389
-- TB77_KJV: 28,764
-- T2010_KJV: 26,530
-- TBR17_KJV: 19,814
-- others: ~20
```

**Answer:** The canonical table was enriched by scripts that generated translation pairs directly from Bible analysis (not through the JSONL pipeline). The 77,243 extra rows include EN→MY translations (154,060 total) that were likely generated by a separate process.

## Q10: Word Alignments Delta

**Question:** Why does `word_alignments_import` (627,000) have more rows than `word_alignments` (385,120)?

**SQL Evidence:**
```sql
SELECT COUNT(DISTINCT ref) FROM word_alignments;       -- 28,903
SELECT COUNT(DISTINCT ref) FROM word_alignments_import; -- 15,665

SELECT COUNT(*) FROM word_alignments w 
WHERE w.ref NOT IN (SELECT ref FROM word_alignments_import);
-- 160,106

SELECT source, COUNT(DISTINCT ref) FROM word_alignments_import GROUP BY source;
-- dict_match: 15,665
```

**Answer:** The import contains 627K rows from `dict_match` source (single source). The canonical table has 385K rows covering 28,903 verses (more verses than the import's 15,665). This means:
1. 241K import rows were filtered out (low-confidence alignments)
2. 160K canonical rows were added by Bible analysis scripts (not in import)

## Q11: Dictionary Delta

**Question:** Why does `dictionary_import` (156,808) have more rows than `dictionary` (103,303)?

**SQL Evidence:**
```sql
SELECT COUNT(DISTINCT zolai) FROM dictionary;       -- 84,490
SELECT COUNT(DISTINCT zolai) FROM dictionary_import; -- 89,019

-- Overlap by zolai key
SELECT COUNT(*) FROM dictionary d JOIN dictionary_import i ON d.zolai = i.zolai;
-- 135,543

-- Dictionary only
SELECT COUNT(*) FROM dictionary d WHERE d.zolai NOT IN (SELECT zolai FROM dictionary_import);
-- 0

-- Import only
SELECT COUNT(*) FROM dictionary_import i WHERE i.zolai NOT IN (SELECT zolai FROM dictionary);
-- 44,287
```

**Answer:** The canonical `dictionary` is a curated subset of `dictionary_import`. All canonical entries exist in the import (0 orphans). The 44,287 import-only entries were filtered out during canonical build — likely duplicates, low-quality, or non-ZVS-compliant entries.

## Additional Questions Resolved

### Q4: Are there duplicate entries in canonical tables?

**Answer:** Yes. `dictionary` has 103,303 rows but only 84,490 distinct Zolai keys (18,813 duplicates). This is because the same Zolai word can have multiple English translations (polysemy).

### Q5: What is the relationship between `*_import` and canonical tables?

**Answer:** `*_import` tables are staging copies from the JSONL pipeline. Canonical tables are curated subsets (with exceptions: `translations` and `word_alignments` are enriched beyond their imports).

### Q6: Are there any tables that should be merged?

**Answer:** Yes:
- `vocab` + `zolai_vocabulary` → merge into `zolai_vocabulary`
- `grammar_patterns` + `grammar_patterns_enhanced` + `zolai_grammar_patterns` → merge into `zolai_grammar_patterns`
- `proverbs` + `zolai_proverbs_idioms` → merge `zolai_proverbs_idioms` columns into `proverbs`

### Q7: What is the canonical build order?

**Answer:** Based on import log timestamps:
1. Bible verses (first import)
2. Word alignments
3. Grammar patterns
4. Phrases
5. Vocab
6. Dictionary
7. Translations
8. Training exercises
9. Proverbs
10. Word collocations

### Q8: Are there any circular dependencies?

**Answer:** No. The dependency chain is linear: source files → import staging → canonical → derived tables.
