# 06 — Orphan Analysis

Rows in canonical with no import source, and vice versa.

---

## Dictionary Import → Canonical

| Metric | Count |
|--------|-------|
| Import entries with no canonical match | 44,287 |
| Canonical entries with no import match | 0 |

**Orphaned import entries (44,287):** These were filtered out during canonical build. Likely reasons:
- Duplicate entries across sources
- Non-ZVS-compliant entries
- Low-confidence translations
- Entries without required fields

**Action needed:** Document the filter criteria used in `build_canonical.py`.

## Translations Import → Canonical

| Metric | Count |
|--------|-------|
| Canonical entries not in import | ~77,243 |
| Import entries not in canonical | ~0 (by text match) |

**Orphaned canonical entries (77,243):** These were generated by enrichment scripts that query the Bible directly, bypassing the JSONL pipeline. This is the correct behavior — the JSONL import was just one source.
