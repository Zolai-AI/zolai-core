# 01 — Table Usage Classification

Each of the 71 tables classified by how it is used at runtime.

## Classification Legend

| Tag | Meaning |
|-----|---------|
| **RUNTIME** | Queried by the running application (zolai-core API, RAG pipeline) |
| **PIPELINE** | Written by the JSONL import pipeline; source of truth for canonical build |
| **DERIVED** | Populated by analysis scripts, not direct imports |
| **STAGING** | Intermediate `*_import` table; raw data before transformation |
| **UNUSED** | Zero rows, placeholder for future work |
| **FTS** | Auto-generated by SQLite FTS5 |
